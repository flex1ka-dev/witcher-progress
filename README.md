# Путь flex1ka

Журнал прохождения The Witcher 3 для чата https://www.twitch.tv/flex1ka .

Прогресс обновляется примерно раз в 10 минут во время игры и после выхода. Публикация GitHub Pages может добавить задержку. После закрытия игры остаётся последний снимок.

Секреты и локальная программа передачи в этот репозиторий не входят.
