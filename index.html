    Подключение игры

    Живые данные прямо из твоего прохождения.

    Ожидаю первый сигнал

    STEAM · ПК · REMASTERED 5.x

    Загрузи сохранение с модом Witcher Path. Сайт начнёт получать данные автоматически.

    1. 01

      Установи мод Witcher Path

      Мод читает журнал и статистику. Он не меняет характеристики, задания или сохранения.

      Скачать скрипт мода ↓
      Куда положить файл

      В папке игры создай mods/modWitcherPath/content/scripts/local/ и положи туда witcher-path.ws. Для установленной здесь игры подготовлен автоматический установщик в папке проекта.

    2. 02

      Загрузи сохранение

      Включи modWitcherPath в менеджере модов игры, если он отключён. Для записи журнала добавь в Steam → Свойства игры → Параметры запуска -net -debugscripts и перезапусти игру. Данные появятся в Документы/The Witcher 3/scriptslog.txt.

    3. 03

      Подключи папку игры

      Для опубликованного сайта выбери папку Документы/The Witcher 3 в Chrome или Edge. Доступ нужен только для чтения. В локальной версии данные подключаются автоматически.

    ◈

    Твои данные остаются на твоём компьютере. Сайт извлекает только записи Witcher Path из локального журнала скриптов или файла телеметрии. Обновление примерно раз в 2 секунды; в паузе игры и фоновых вкладках возможны задержки.

    Если сигнал перестал поступать, сайт сохранит последний снимок и отметит его как устаревший. Совместимость мода проверяется при запуске игры.
